# Chain-first 意图关键字（平台 L1）

| 用户说法 | intent | MCP Tool |
|----------|--------|----------|
| 开发/规划…链路 | PLAN_CHAIN | plan_chain |
| 生成元件 | SCAFFOLD_COMPONENT | scaffold_component |
| 组链 | COMPOSE_CHAIN | validate_chain + Admin suggest |
| Mode1/2/3 | BIND_HTTP | 读 http-three-mode Pattern |
| 生成场景 | GEN_PLAYGROUND_SCENE | gen_playground_scene |
| 验证 | VERIFY | validate_chain |
| 反馈/采纳 | RECORD_FEEDBACK | record_learning_event |
| 总结沉淀 | DISTILL_PATTERNS | distill_patterns |
| 检索经验 | SEARCH_PATTERNS | search_patterns |
| 团队共享 | SHARE_PATTERN | share_pattern |

工作流顺序：`plan → scaffold(gap) → compose → validate → bind_http → scene → record → distill`
