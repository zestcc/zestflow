# OpenAPI Specification Directory

> **Version** 0.1.0 · **Updated** 2026-06-08 · **Language** English · [简体中文](README.md)

This directory holds OpenAPI 3 JSON snapshots exported from a running Admin instance, kept in sync with `zestflow-admin` Controller source code.

| File | Description |
|------|-------------|
| `admin-api.json` | Full Admin REST API spec; **generated by script, commit before release** |

**Note:** Executor Netty (`:20550`) and Collector Netty (`:20650`) are outside springdoc scan scope. See manually maintained sections in [API.md](../reference/API.en.md).

---

## Regenerate

**Prerequisite:** Admin running (local profile, default `http://localhost:8080`)

```powershell
powershell -File scripts/docs/export-openapi.ps1
```

```bash
bash scripts/docs/export-openapi.sh
```

Output writes to `admin-api.json` in this directory. Run before release and commit the diff.

---

## Browse online (local only)

Copy `application-local.example.yml` → `application-local.yml`, then start Admin:

- Swagger UI: http://localhost:8080/swagger-ui.html
- JSON: http://localhost:8080/v3/api-docs

Production (`prod` profile) **forcibly disables** OpenAPI and Swagger UI.
